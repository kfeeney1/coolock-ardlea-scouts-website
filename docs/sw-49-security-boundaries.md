# SW-49 security boundaries

Deputy Group Leader parity is intentionally operational, not administrative.

The shared Group Leadership bundle does not change `adminUsers.role`, cannot create Admin or Super Admin authority, cannot approve leader/parent accounts, cannot mutate protected Super Admin accounts, and cannot bypass section/workflow restrictions for consent, medical information or event records.

Formal Group Council and Group Leaders meeting creation remains Admin-only under the current authoritative policy even though Group Leader and Deputy Group Leader may read the protected history. This is treated as an explicit non-delegable operation until a separately reviewed policy changes it.
