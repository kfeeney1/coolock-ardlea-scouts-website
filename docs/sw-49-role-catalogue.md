# SW-49 role catalogue distinction

System access roles: Parent / Guardian, Leader, Admin, Super Admin.

Scouting appointments: Group Leader, Deputy Group Leader, Group Secretary, Group Treasurer, Group Quartermaster / Bo'sun, Group Chairperson, Group Youth Champion, Section Leader, Assistant Section Leader, Programme Scouter, Scouter.

Deputy Group Leader is in the second list only. Appointment parity never changes the first list.
