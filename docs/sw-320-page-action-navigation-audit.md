## Expanded site-wide control inventory — 12 October 2026

The live route table in `src/App.tsx`, rendered TSX components and shared control source were reviewed at base `8ce0b913f8afdef0f581209689e92b9a3fdd1136`. The audit now includes page actions, content and contact references, links in tiles/tables/forms, error/retry states and dialogs. Most in-app navigation was already rendered by MUI `Button`, linked `Paper`, or clickable `Chip`; the defects were text-only MUI `Link` elements, text-variant actions, buttons inheriting MUI's text default, plus the two unstyled Event audience operations.

Role scope recorded for these control groups follows `src/security/permissionRegistry.ts` and the route guards, without changing them: public routes are anonymous; Parent Portal/event-consent controls require a signed-in Parent / Guardian with an approved linked member and remain scoped to the selected child; ordinary `/leader/*` routes require the existing Leader/Admin/Super Admin access and then retain each page's existing assigned-section or group appointment permission checks. Current appointment scope includes Group Leader, Deputy Group Leader, Group Secretary, Group Treasurer, Group Quartermaster / Bo'sun, Group Chairperson, Group Youth Champion, Section Leader, Assistant Section Leader, Programme Scouter and Scouter. Finance, equipment, consent, event, badgework and meeting controls retain their existing permission registry / component checks. `/leader/settings` retains its dedicated settings guard and `/leader/system` remains Super Admin-only. Controls shown inside a page inherit that page's current permitted roles; disabled/read-only states are unchanged.

The shared theme now defaults unqualified MUI actions to outlined buttons in all three themes, so a future `<Button>` does not silently render as link-like text. Header and Leader Dashboard menu controls carry `data-control-role="menu"` and keep their established menu presentation. `ActionLinkButton` styles inline/internal/external/contact links as outlined controls while preserving RouterLink or native anchor semantics, href, target, rel, download and keyboard behavior. `scripts/check-visible-control-contract.mjs` guards the theme defaults, unapproved text variants, direct MUI content links, telephone text anchors, and Event audience bulk-control semantics/presentation. Its only scoped exceptions are the standard header/dashboard menu controls; standard `MenuItem`/`Tabs`/checkboxes/selects; clickable record cards/chips; and non-rendered generated download anchors or image previews.
