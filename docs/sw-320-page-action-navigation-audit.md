# SW-320 page-action navigation audit

Audit completed against the public and authenticated routes on main at f06084e1 (8 October 2026). The source scan covered shared navigation, dashboard tiles, record-detail return controls, forms, and route actions across public pages, Leader and Parent areas, consent/medical, meetings/events, badgework, equipment/stores/QM, finance, Join Us, Scouter/profile, administration, and reports.

| Route or area | Action / candidate | Decision |
|---|---|---|
| /leader/access and /leader/access/:leaderUid | Leader record tiles; “Back to leaders” including the unavailable-record state | Converted to React Router links using the existing shared button/card presentation. The detail link retains the current filter query; permission checks and route guards are unchanged. |
| /leader/equipment | “Open QM Reports”; equipment record title and “Edit”; “Move Store”; “View reported issues”; recent issue activity | Converted route transitions to links. Inventory cards remain non-interactive containers so their History, Archive and other controls are not nested inside an anchor. Issue and equipment IDs remain in their destinations. |
| /leader/equipment/issues, /leader/equipment/:id/move-store, /leader/qm-reports | “Back to Equipment & Stores”; “Back to equipment record”; “Open Equipment & Stores”; “Review current equipment issues” | Converted fixed destinations to link-buttons. QM view and issue context are preserved where present. “Cancel” in the move form remains an operation button. |
| /leader/events and /leader/events/:eventId | “Add Event”; “Back to Events” | Converted to shared link-buttons. Event-record action destinations and event authorization remain unchanged. |
| /leader/join/:joinId | “Return to Join Us Management” on the unavailable-record state | Converted to a link-button. “Back to enquiries” remains an operation button while edits are dirty because it opens an unsaved-changes confirmation. |
| /leader/requests and /leader/access/:leaderUid | Approved leader-request card → Leader Access | Converted approved request cards to Router links. Pending request cards remain buttons because they open the review workflow. |
| /leader/profile/consent | “Back to My Profile” in the Scouter form and submitted state | Converted to a link-button targeting the existing profile route. |
| Header and Leader Dashboard navigation | Public and authenticated route menu items, dashboard links | Retained; these already use Router links styled as buttons/menu items. The public Parent Login entry remains removed per SW-359; the authenticated Parent Portal link remains. |
| Dashboard and administration | Open/manage tiles, system overview actions, reports and operational links | Retained where already implemented as shared link-buttons or full-card Router links. Their role visibility and route guards remain in place. |
| Member Management, Consent, medical, Parent Portal, Scouter/profile | Open record/form, medical indicators, Back/Return controls, Parent Portal section controls | Retained where the existing Router link or button pattern already presents a clear page action and carries the member/consent/return context. Existing role and privacy guards remain unchanged. |
| Meetings and Events workflows | Back/Continue, create/edit, attendance, audience and meeting navigation | Retained where controls already use link-buttons, or where a button performs local state, save, close, copy or an unsaved-navigation confirmation before changing route. |
| Public content and genuine inline links | Contact email, Privacy → Contact, telephone links, maps, policy documents, badgework provenance “View source”, receipt previews, generated reports, email/WhatsApp and downloads | Retained as native content/external/download links. These remain contextual hyperlinks or file/share operations, not application page-action labels. |

Regression coverage checks the Leader Access detail-to-list journey, preserved filter query, direct deep links, browser Back, keyboard activation/focus, mobile target dimensions and overflow; member and consent/medical return paths; the event list transition; the QM report round trip and view query; ordinary-leader denial at the Leader Access route; and an inline Privacy → Contact link.
